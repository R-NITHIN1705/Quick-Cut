# Chrome Web Store listing

## Short description

Capture text and links you choose, then copy or save them on your device.

## Long description

QuickCut is a focused capture tool for text and links on the page you are viewing. Start a capture from the extension, choose the text you need or capture a link, then copy it or find it later in your local history.

- Select a passage by choosing its start and end points.
- Save a link without navigating away from the page.
- Search, copy, open, or remove saved captures from the popup.
- Choose optional sound feedback and adjust the history limit in Settings.
- Use keyboard shortcuts to start capture actions.

QuickCut only accesses the current tab after you ask it to capture something. Captures and preferences are stored locally on your device.

## Single-purpose statement

QuickCut's single purpose is to let users capture text and links from the current tab and keep those chosen items in a searchable local library.
