# Privacy practices dashboard checklist

Suggested answers for the Chrome Web Store Privacy practices tab:

- **Single purpose:** Capture text and links that users explicitly select from the current tab and store them in a searchable local library.
- **Data collected:** No data is transmitted to or collected by the developer. The extension processes only user-selected text or links and stores them locally when the user captures them.
- **Data use:** User-selected content is used only for capture, clipboard copy, and the local history feature.
- **Data transfer:** None. QuickCut makes no network requests and sends no user data to the developer or other parties.
- **Data storage:** Captures and preferences are stored in Chrome local extension storage on the user's device.
- **Sale or sharing:** No sale or sharing of user data.
- **Analytics or tracking:** None.
- **Remote code:** None. QuickCut's executable code is packaged with the extension.
- **Privacy policy URL:** Publish the text in `privacy-policy.md` at a publicly accessible URL and enter that URL in the dashboard.
- **Permission explanations:** Use the matching one-sentence justifications in `permissions.md`.

Review these answers against the current Chrome Web Store dashboard wording before submitting. In particular, disclose that user-selected website text and links are processed locally to provide the requested capture feature.
